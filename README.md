# High Score Tracker
***
This project is a gambling game that the user can play. There are different modes in the game like blackjack, roulette, dice, bacarat, a slot machine, and a lottery. At the end (either once you win and beat the game or you quit), it will save your score and also save your high score. It also uses ASCII art throughout the game so be sure to have your terminal expanded all the way up for the best experience. It's a roguelike where you gamble your money so that at the end you can make the most money possible. You can login or register as a new user. Logging in allows it to compare your new score with your high score. Registering creates you a new profile with no history in the game.

## How to use High Score Tracker
***
1. Running the code will instantly bring you into the game.
2. Play and either beat the game or quit.
3. Upon leaving the game, you will be asked if you have an account or if you would like to make a new account to save your score.
4. If you have an account and would like to log in, you must give your username and password.
5. If you would like to make a new account then it will have you ask for you username and then make a password.
6. Your account will be saved.
You will need Python to run this successfully.
